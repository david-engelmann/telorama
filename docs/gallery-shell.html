telorama

A visualization engine for OpenTelemetry data. An agent describes the diagram it wants in a small structured document, telorama checks the description against a set of honesty rules, works out the geometry itself, and renders a finished picture that can appear inside an AI chat, a pull request, or a plain file. This page shows every scene family the engine renders, drawn from the test fixtures by the renderer itself.

A session, frame by frame

A live agent session stepping through its frames. The whole picture is replaced at each turn boundary, the way the live view works, and each frame is a complete deterministic render of the turns that exist at that moment.

An incident, composed

The incident composition over the checkout traces. The engine picks the failing service, builds the scene that explains it, and the investigation layer puts its findings strip at the head of the picture.

Every picture on this page is the renderer's own output, produced by the same code path the command line tool uses. A test in the repository re-derives each picture and fails if this page ever drifts from the current renders.
